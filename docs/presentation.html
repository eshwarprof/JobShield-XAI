1. Introduction & Motivation

  • Explosion of Recruitment Fraud Digitized job hunting has led to sophisticated fraudulent job ads seeking quick gains.
  • Candidate Harm & Abuse Consequences range from monetary scams (application/training fees) to identity theft (SSN/details).
  • The Opaque "Black-Box" ML Problem Traditional classifiers yield binary predictions without explanations, offering no auditable evidence.
Core Project Objective

Provide job seekers with transparent explanations and structured warnings rather than simple opaque classification labels, giving them actionable confidence to verify suspicious postings.

3. System Architecture

Architecture Highlights

• Decoupled Pipelines: Frontend handles file ingestion and dashboard rendering, Backend handles rate limiting & auth, and FastAPI AI remains isolated for ML workloads.

• Audit Logs: Every inference run with classification results, trust scores, and signals is recorded to MongoDB for historical tracking.

4. Dataset & Data Imbalance Insights

EMSCAD Corpus Analysis

• Data Corpus: Built using the EMSCAD corpus comprising 17,880 rows containing details on 18 posting attributes.

• Class Imbalance: Fraudulent job postings represent only 4.84% (866) of the corpus, vs. 95.16% (17,014) legitimate postings.

• Imbalance Management: During fine-tuning, class weights are assigned in the cross-entropy loss function to ensure the model doesn't bias entirely toward the majority class.

Heuristic Correlation: Missing text fields correlate heavily with fraud: 67.78% of fraudulent postings lack a `company_profile` compared to only 15.99% of legitimate ads.

5. AI Classification Pipeline

01
Multi-Input Ingest

Parses scraped URLs, extracts text from PDFs (PyMuPDF), or performs OCR on image screenshots (EasyOCR).

02
Clean & Tokenize

Strips emojis/HTML tags, normalizes text representations, and tokenizes strings using BERT's WordPiece tokenizer.

03
BERT Inference

Feeds clean token matrices to fine-tuned BERT-base-uncased. A decision threshold of 0.65 yields the binary call.

04
Score & Explain

Triggers Trust, Severity and Risk categorization calculations. Runs live LIME explainer per instance.

Generalization: The model is not just lookup based. Standard integration tests include verifying unseen sample postings (e.g. KMIT faculty listings), which pass successfully based solely on learned textual patterns.

7. Deterministic Trust Score Engine

  • Objective Scorecard (0–100) Ensures complete clarity and accountability. No second black-box model is stacked on top of BERT.
  • 8 Defined Penalty Heuristics Triggers penalty deductions for domain mismatches, missing company logo, registration fee, layout mismatches, etc.
  • Input Layout Fallbacks Correctly handles unstructured text channels (PDF/OCR text) without incorrectly penalizing missing field structures.

8. Risk & Severity Engines

Fraud Severity Score (0–100)

Assesses the high-harm level of a suspicious job posting based on immediate danger signs:

  • • Asking for upfront registration fees.
  • • Financial validation (e.g. requesting bank account details).
  • • Insecure contact handles (WhatsApp, Telegram recruitment channels).
Risk Categorization Matrix

Combines fine-tuned BERT probability and heuristic Trust Scores:

  • • Maps probability-trust coordinates to 4 discrete categories.
  • • Escalate safeguards: Low BERT probability is overridden if critical trust anomalies occur, escalating risk categories to Medium.

10. Key Achievements & Future Directions

Research Contributions

  • Unifies Deep BERT models with interactive dual-XAI explanation scorecards.
  • Implements independent rule-based Trust & Severity validators to verify output context.
  • Accommodates multi-input scanning paths (Text, PDFs, image-OCR).

Future Roadmap

  • Browser Extension: Scans LinkedIn and job boards directly in real-time.
  • Multilingual Scans: Fine-tunes classifiers for Spanish, German, French.
  • API Moderation: Plug-and-play validation APIs directly for online platforms.
